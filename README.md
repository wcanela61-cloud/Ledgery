# Ledgerly — Reseller Dashboard

A single-file web app for tracking reseller inventory and sales: dashboard, inventory, and sales views, with theme ("vibe"), color, and font settings.

## Usage

Open `index.html` in a browser — no build step or server required. The app starts empty. Your items, sales and theme settings are saved in the browser's `localStorage`, so they stay when you reload. Settings → Data → **Erase all data** clears them.
